# Playbook core (every project)

Loaded in every session from ai-dev-standards-playbook. Keep this file under 1 KB.

- Answer first, then explain. Match length to the ask.
- Work on a branch; small PRs; conventional commits; a CHANGELOG line for visible changes.
- Read before editing; follow the project's existing patterns over these defaults.
- Security: sanitize input, escape output, nonces and capability checks on every form and admin action.
- Accessibility: WCAG 2.2 AA, one `h1`, sequential headings, visible focus.
- Never invent metrics, testimonials or client names.
- Token discipline: `rg` before opening big files; read only what you need; summarize logs; don't re-run passing checks.
- Verify versioned APIs (hooks, Tailwind v4, Next, Node) against official docs: `doc-references` skill.
- Ask only for DNS, PHP versions, production database writes, deletions, spending money and secrets.
