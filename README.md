# ⚡ AI Dev Standards & Playbook

> A running, always-updated guidebook, AI ruleset, and idea share for developers building fast, accessible portfolio sites, agency projects, and WordPress themes using **Claude Code** (Anthropic's CLI agent).

Created and maintained by **[Matt Hummel](https://matthummel.com)** — Full-stack & WordPress Developer in Gettysburg, PA.

---

## 🎯 What Is This?

This repository serves a dual purpose:
1. **Your AI Ruleset Baseline:** A production-tested context file (`CLAUDE.md`) you can drop into any project root so Claude Code acts as a senior WordPress engineer, UX designer, and technical SEO partner.
2. **An Evolving Playbook:** A live reference for modern web standards, project scoping, pre-launch checklists, and prompt engineering strategies.
